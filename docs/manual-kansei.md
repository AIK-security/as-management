# 配置管理システム かんたん操作マニュアル

**2026-09-16 版／管制ご担当者さま向け**

---

## はじめに

- **いま入っているデータは全部ニセモノです。** 氏名も現場名も架空のものです。
- **好きなだけ触って、好きなだけ壊してください。** 元に戻せます。
- 「使いにくい」「これじゃない」と思ったところを教えてください。**直すために触ってもらっています。**

**ひらく場所**　https://as-management-ten.vercel.app

---

## 画面は5つ

左側のメニューから移ります。

| メニュー | 何をする場所か |
|---|---|
| **配置ボード** | **1日ぶん**の配置を組む。いちばん使う画面 |
| **A表（週）** | **1週間ぶん**をまとめて見る。ここでも配置を動かせる |
| **休み** | **1か月ぶん**の休みを入れる |
| 連絡作成 | 隊員への連絡の宛先と文面をつくる |
| マスタ（現場・隊員・得意先・NG） | 台帳。名前や必要人数などを直す場所 |

## 1. 配置ボード ── 1日ぶんを組む

### 画面の見かた

- **四角い箱が1つ＝1つの枠**（その現場の、その時間帯）
- 箱の中の名札が、そこに入っている隊員です
- **右側が「隊員プール」**＝まだどこにも入っていない人

### 隊員を入れる

**プールの名札を、入れたい箱まで引っぱって離す。** それだけです。

- 箱から箱へ**直接**動かすこともできます
- 箱から出すときは、**プールまで引っぱって**離します

### 色の意味（ここだけ覚えてください）

| 色 | 意味 |
|---|---|
| **箱の左のふち／オレンジ** | **仮組み**（まだ決まっていない） |
| **箱の左のふち／緑** | **確定**（決まった） |
| **赤い字** | **足りない**、または**入れてはいけない人**（NG・資格なし） |
| 灰色 | 中止になった枠 |

### 決まったら「確定」にする

- **1つずつ**：箱の中の「仮組み」を押すと確定になります。もう一度押すと仮組みに戻ります
- **まとめて**：画面いちばん上の **［一括確定］** を押すと、いま見えている仮組みが全部確定になります

> **確定したあとでも直せます。** 当日の変更はあって当たり前なので、止めていません。
> ただし確定した枠の中身を変えると、**自動的に仮組みに戻ります**（変わったことが分かるように）。

### そのほかの操作

| やりたいこと | どうするか |
|---|---|
| 別の日を見る | 上の **◀ ▶**。［今日］で今日に戻る |
| 夜勤を見る | 上の **［夜勤］** |
| 会社を絞る | 上のほうに並んでいる得意先のボタン |
| 現場を足す | **［＋ 現場を追加］** |
| 時刻・人数・班を直す | 箱の **［編集］** |
| 中止にする | 箱の **［中止］**（枠と人はそのまま残ります） |
| 枠ごと消す | 箱の **［削除］**（人も一緒に消えます。確認が出ます） |

## 2. A表（週）── 1週間をまとめて見る

**左メニューの「A表（週）」**

- 横が7日、縦が現場です
- **ここでも名札を引っぱって動かせます。** 別の日へ移すこともできます
- 列見出しの日付を押すと、**その日が基準日**になります（右のプールがその日のものに変わります）
- 同じ人が同じ時間に2か所に入っていると、**「重複」と赤く出ます**

> **一括確定はここにはありません。** 1日のつもりで押すと7日ぶんが確定してしまうためです。
> 確定は配置ボード（1日の画面）でやってください。

## 3. 休み ── 1か月ぶんを入れる

**左メニューの「休み」**

縦が隊員、横が日付です。

### 入れかた

1. 上の **［有給］［休み］［日勤のみ休み］［夜Aのみ休み］［夜Bのみ休み］** から**入れたいものを1つ選ぶ**
2. あとは**そのままマスを押していく**だけ

消すときは **［消す］** を選んでからマスを押します。

### マスの文字

| 文字 | 意味 |
|---|---|
| **有** | 有給（終日） |
| **休** | 休み（終日） |
| **日・A・B** | **その区分だけ休み**（ほかは出られる） |
| **・** | その日は配置が入っています |
| **赤いマス** | 配置が入っている日に休みが入っています（**確認してください**） |

### 休みを入れると配置がどう変わるか

- **終日の休み**　…　配置ボードのプールから**消えます**
- **日勤のみ休み**　…　**日勤の画面からだけ**消えます（夜勤には出てきます）
- 休んでいる人は、配置ボードの**右下「非現場」に名前が出ます**

> いまは**管制のかたが入力する**形です。
> 隊員が自分で申請して、その結果が本人に伝わるしくみは**あとの段階**で作ります。

## 4. こういうときは

| 困ったこと | どうするか |
|---|---|
| 間違えて動かした | **もう一度引っぱって戻す**だけです |
| 名札が見つからない | プールの上の**検索欄**に名前を入れてください |
| 入れられないと言われた | **同じ人が同じ時間に2か所**に入っています。どちらかを外してください |
| 赤字が出たが入れたい | **NG や資格不足は止めていません。** 警告だけなのでそのまま入れられます |
| 画面が小さくて見づらい | **Ctrl キーを押しながら「＋」**で大きくなります（元に戻すのは Ctrl と「0」） |
| おかしくなった | **画面を再読み込み**（F5）してください |

## 5. まだ できないこと

いまの時点では、次のことはできません。**これから作ります。**

- **べんり君（ShiftMax）への引き渡し** … ボタンはありますが、まだ押せません
- 印刷
- 隊員のかたが自分で休みを申請すること
- 請求・給与にかかわること

使ってみて、次のようなことがあったら**どんな小さなことでも**教えてください。

- **手が止まったところ**（どうすればいいか分からなくなった場所）
- **いつものやり方と違うところ**
- **言葉が分かりにくいところ**（画面の名前・ボタンの名前）
- **この順番じゃない、という手順**

> **ダメ出しが多いほど助かります。**
> いま直すのがいちばん安く、稼働してからだと直しにくくなります。
