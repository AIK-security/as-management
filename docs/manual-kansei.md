# 1. 配置ボード

## 1-1. 画面の見かた

### 上の帯

| 表示 | 意味 |
|---|---|
| **◀ 2026/09/16（水） ▶** | 見ている日。◀ ▶ で前後の日へ |
| **［今日］** | 今日以外を見ているときだけ出る |
| **［日勤］［夜勤］** | 押して切り替える |
| **仮組み ○** | まだ決まっていない枠の数 |
| **確定 ○** | 決まった枠の数 |
| **未充足 ○** | **人が足りない枠の数** |
| 得意先のボタン（アルファ建設 18 不足5 …） | 押すとその会社だけになる。**［すべて］**で戻る。<br>**赤い「不足5」** はその会社で人が足りない枠の数 |

### 箱（＝1つの枠）

```
┌─────────────────────────────┐
│ アルファ建設                  ← 得意先
│ アルファ 駅前工区              ← 現場名
│ 仮組み        中止 編集 削除    ← 状態と操作
│ 07:00–16:00 日勤 B班 休45  3/3名
│ ┌──────┐┌──────┐┌──────┐
│ │鈴木42 ││高橋43 ││田中44 │   ← 名札
│ │ L    ││      ││ 交2  │
│ └──────┘└──────┘└──────┘
└─────────────────────────────┘
```

| 表示 | 意味 |
|---|---|
| **07:00–16:00** | 勤務時間 |
| **日勤／夜A／夜B** | 区分 |
| **B班** | 班名 |
| **休45** | 休憩45分 |
| **3 / 3名** | **入っている人数 / 必要な人数**。足りないと**赤字** |
| **空き ＋** | 人が入っていない場所 |

### 箱の左のふち（色）

| 色 | 意味 |
|---|---|
| **オレンジ** | **仮組み**（まだ決まっていない） |
| **緑** | **確定**（決まった） |
| **灰色** | **中止**（現場名に取り消し線が付く） |

### 名札の記号

| 記号 | 意味 |
|---|---|
| **L**（黒） | **隊長** |
| **交1 / 交2**（緑） | 交通誘導警備業務検定 1級 / 2級 |
| **経** | **この現場に入った経験がある** |
| **協** | 協力会社の隊員 |
| **NG**（赤） | **この現場に入れてはいけない人**。押すと理由が出る |

### 右側

| 表示 | 中身 |
|---|---|
| **隊員プール（未配置）** | まだどこにも入っていない人。上の数字が人数 |
| **非現場** | 休みの人など。**名前が出る** |
| **貸出中（協力会社へ）** | 他社へ出している人 |
| 帯を閉じる／開く | 右上の **‹ ›** |

### 下の帯

**要確認 ○件** … 押すと中身が開きます。
**止めているのは時間帯の重複だけです。** NG も資格不足も**警告だけ**で、配置はできます。

---

## 1-2. 操作

### 人を入れる・動かす・外す

| やりたいこと | 操作 |
|---|---|
| **入れる** | プールの名札を、**入れたい箱まで引っぱって離す** |
| **別の箱へ移す** | 箱の名札を、**別の箱まで引っぱって離す** |
| **外す** | 箱の名札を、**プールまで引っぱって離す** |
| **隊長にする／外す** | 名札を**1回押して選び**、右上に出る **L** を押す |

### 確定する

| やりたいこと | 操作 |
|---|---|
| **1つだけ確定** | 箱の **［仮組み］** を押す |
| **確定を戻す** | 箱の **［確定］** を押す |
| **まとめて確定** | 上の **［一括確定（○）］**。**いま画面に見えている**仮組みが対象 |

**確定したあとでも直せます。**
ただし確定した枠の**中身を変えると仮組みに戻ります**。

### 枠をさわる

| やりたいこと | 操作 |
|---|---|
| **現場を足す** | 上の **［＋ 現場を追加］** |
| **時刻・人数・班・メモを直す** | 箱の **［編集］** |
| **中止にする** | 箱の **［中止］**。枠も人も残り、灰色になる |
| **中止をやめる** | もう一度 **［中止］** |
| **枠ごと消す** | 箱の **［削除］** → **［削除する］**。<br>**入っている人も一緒に消えます**（人数が出ます） |

### キーボード

| キー | 動き |
|---|---|
| **↑ ↓** | 枠を選ぶ |
| **L** | 選んでいる名札を隊長にする／外す |

# 2. A表（週）

## 2-1. 画面の見かた

- **横が7日、縦が現場**です
- **色の付いた列と白い列が交互**になっています（列を見分けるためで、意味はありません）
- 列見出しの**青い列が「基準日」**です。右のプールは**その日**のものです
- **「—」** … その日はその現場に枠がありません
- **「重複」（赤）** … その人は**同じ時間に別の場所**にも入っています
- **「○名不足」（赤）** … 人が足りません

## 2-2. 操作

| やりたいこと | 操作 |
|---|---|
| **配置を動かす** | 名札を引っぱる。**別の日へも移せます** |
| **基準日を変える** | 列見出しの**日付を押す** |
| **前の週／次の週** | 上の **◀ ▶** |
| **その日の配置ボードへ** | 右上の **［○/○ の配置ボードへ］** |

**一括確定はこの画面にはありません。** 確定は配置ボードで行います。

# 3. 休み

## 3-1. 画面の見かた

- **縦が隊員、横が日付**です
- 上の **休み ○件** … その月に入っている休みの数

### マスの文字

| 文字 | 意味 |
|---|---|
| **有** | 有給（終日） |
| **休** | 休み（終日） |
| **日 / A / B** | **その区分だけ休み**。ほかの区分は出られる |
| **・** | その日は**配置が入っています** |
| **赤いマス** | **配置が入っている日に休みが入っています** |

マスにカーソルを乗せると中身が文字で出ます。

## 3-2. 操作

1. 上の **［有給］［休み］［日勤のみ休み］［夜Aのみ休み］［夜Bのみ休み］** から**1つ選ぶ**
2. **マスを押す**

消すときは **［消す］** を選んでからマスを押します。

| やりたいこと | 操作 |
|---|---|
| **前の月／次の月** | 上の **◀ ▶** |
| **今月に戻る** | **［今月］** |
| **隊員を探す** | 右上の入力欄に名前 |
| **休みのある人だけ見る** | 右上のチェック |

## 3-3. 休みを入れると配置がどう変わるか

| 入れた休み | 配置ボードのプール |
|---|---|
| **有給・休み（終日）** | 日勤・夜勤の**どちらからも消える** |
| **日勤のみ休み** | **日勤からだけ消える**（夜勤には出る） |
| **夜Aのみ休み** | 夜勤に**残る**（夜Bには出られるため）。夜A・夜B の**両方**を入れると消える |

消えた人は、配置ボードの右下 **「非現場」に名前が出ます**。

---

# 4. こういうときは

| 困ったこと | どうするか |
|---|---|
| **間違えて動かした** | もう一度引っぱって戻す |
| **名札が見つからない** | プール上の**検索欄**に名前を入れる |
| **「置けません」と出た** | **同じ人が同じ時間に2か所**に入っています。どちらかを外す |
| **赤字が出たが入れたい** | NG・資格不足は**警告だけ**です。そのまま入れられます |
| **一括確定が押せない** | 確定できる仮組みが**画面に無い**ときは押せません |
| **画面が小さい** | **Ctrl** を押しながら **＋**（戻すのは **Ctrl** と **0**） |
| **表示がおかしい** | **F5** で読み込み直す |

---

## まだ押せないボタン

**［べんり君へ引き渡し］**（グレーの点線）… まだ中身がありません。押しても動きません。
