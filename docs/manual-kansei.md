# 1. 配置ボード

## 1-1. 画面の見かた

### 上の帯

| 表示 | 意味 |
|---|---|
| **◀ 2026/09/16（水）▾ ▶** | 見ている日。◀ ▶ で前後の日へ。<br>**日付を押すとカレンダー**が開き、選んだ日へ一気に飛ぶ。**今日へはカレンダーの［今日］** |
| **［日勤］［夜勤］** | 押して切り替える |
| **仮組み ○** | まだ決まっていない枠の数 |
| **確定 ○** | 決まった枠の数 |
| **未充足 ○** | **人が足りない枠の数** |
| 右端の札 **○ 未確認** ／ **✓ 確認済み（名前・日時）** ／ **! 確認後に変更あり** | この日の配置を確認したかどうか（日勤・夜勤まとめて1つ）。<br>**緑**＝確認済みで、その後変わっていない／**黄色**＝確認の後に配置が変わった（いつから変わったかを出す） |
| 得意先のボタン（アルファ建設 18 不足5 …） | 押すとその会社だけになる。**［すべて］**で戻る。<br>**赤い「不足5」** はその会社で人が足りない枠の数 |

### 箱（＝1つの枠）

```
┌─────────────────────────────┐
│ アルファ建設                  ← 得意先
│ アルファ 駅前工区              ← 現場名
│ 仮組み        中止 編集 削除    ← 状態と操作
│ 07:00–16:00 日勤 休45      3/3名
│ ┌──────┐┌──────┐┌──────┐
│ │鈴木42 ││高橋43 ││田中44 │   ← 名札
│ │ L    ││      ││ 交2  │
│ └──────┘└──────┘└──────┘
└─────────────────────────────┘
```

| 表示 | 意味 |
|---|---|
| **07:00–16:00** | 勤務時間 |
| **日勤／夜A／夜B** | 区分 |
| **休45** | 休憩45分 |
| **3 / 3名** | **入っている人数 / 必要な人数**。足りないと**赤字** |
| **空き ＋** | 人が入っていない場所 |

### 箱の左のふち（色）

| 色 | 意味 |
|---|---|
| **オレンジ** | **仮組み**（まだ決まっていない） |
| **緑** | **確定**（決まった） |
| **灰色** | **中止**（現場名に取り消し線が付く） |

### 名札の記号

名札の名前は**略称**です（空白は詰め、9文字以上は8文字まで）。乗せると氏名が全部出ます。
**期限切れの資格は出ません。**

| 記号 | 意味 |
|---|---|
| **L**（黒） | **隊長** |
| **K / R / D**（黒） | **職種**。K＝検定、R＝列車見張、D＝ドライバー（A表と同じ）。何も無ければ交通誘導 |
| **K! / R!**（黄） | 職種を付けたが、その人に**資格の登録が無い**（付けることはできます） |
| **中**（名前が薄い） | **この人だけ現着中止**。人数には数えたまま |
| **交1 / 交2**（緑） | 交通誘導警備業務検定 1級 / 2級 |
| **東急・京王・小田急 …**（緑・箱の中） | **列車見張**。その現場に「必要な資格」として設定した鉄道会社のものだけ出る |
| **列3**（緑・プールと A表） | **列車見張を3社ぶん持っている**。乗せると会社名が出る |
| **経** | **この現場に入った経験がある** |
| **協** | 協力会社の隊員 |
| **NG**（赤） | **この現場に入れてはいけない人**。押すと理由が出る |
| **日勤済／夜勤済**（黄・プールだけ） | **この日はもう反対側の勤務に入っている人**。<br>日勤のあと夜勤に入れるときに使う。入れることはできる |

### 右側

| 表示 | 中身 |
|---|---|
| **隊員プール（未配置）** | この区分（日勤／夜勤）にまだ入っていない人。上の数字が人数。**フリガナ順**に並ぶ。<br>反対側の勤務に入っている人は **日勤済／夜勤済** の印付きで出る |
| **非現場** | 休みの人など。**名前が出る** |
| **貸出中（協力会社へ）** | 他社へ出している人 |
| 帯を閉じる／開く | 右上の **‹ ›** |

### 下の帯

**要確認 ○件** … 押すと中身が開きます。
**止めているのは時間帯の重複だけです。** NG も資格不足も**警告だけ**で、配置はできます。

## 1-2. 操作

### 人を入れる・動かす・外す

| やりたいこと | 操作 |
|---|---|
| **入れる** | プールの名札を、**入れたい箱まで引っぱって離す** |
| **別の箱へ移す** | 箱の名札を、**別の箱まで引っぱって離す** |
| **外す** | 箱の名札を、**プールまで引っぱって離す** |
| **隊長・職種・現着中止を付ける** | 名札を**1回押して選ぶ**と、名札の上に吹き出しが出る。<br>**［隊長］［現着中止］**、職種は **［なし］［K 検定］［R 列車］［D ドライバー］** から押す。<br>押してあるものは**藍色**。もう一度押すと外れる（職種は［なし］）。枠の外を押すか Esc で閉じる |

### 確定する

| やりたいこと | 操作 |
|---|---|
| **1つだけ確定** | 箱の **［仮組み］** を押す |
| **確定を戻す** | 箱の **［確定］** を押す |
| **まとめて確定** | 上の **［一括確定（○）］**。**いま画面に見えている**仮組みが対象 |

**確定したあとでも直せます。**
ただし確定した枠の**中身を変えると仮組みに戻ります**。

### 確認する

| やりたいこと | 操作 |
|---|---|
| **この日の配置を見終わったと残す** | 右端の札 **［○ 未確認｜確認する］** を押し、出てきた画面で **［確認済みにする］**。日勤・夜勤をまとめて1回 |
| **確認の後に配置が変わった** | 札が黄色の **「! 確認後に変更あり」** になる。見直したら札（**もう一度確認**）を押す |

確認したあとも配置はふつうに直せます。直すと「確認後に変更あり」に変わるだけです。

### 枠をさわる

| やりたいこと | 操作 |
|---|---|
| **現場を足す** | 上の **［＋ 現場を追加］** |
| **別の日の枠をまとめて写す** | 上の **［別の日から複写］**（下の「別の日から複写」） |
| **時刻・人数・メモを直す** | 箱の **［編集］** |
| **中止にする**（前日・当日朝に中止） | 箱の **［中止］**。枠も人も残り、灰色になる。べんり君へ渡す CSV には**出ません** |
| **枠ごと現着中止にする** | 箱の **編集** で区分を「日勤現中／夜勤現中」に変える。一部の人だけなら名札の **中** |
| **中止をやめる** | もう一度 **［中止］** |
| **枠ごと消す** | 箱の **［削除］** → **［削除する］**。<br>**入っている人も一緒に消えます**（人数が出ます） |

### 別の日から複写

**似た日の枠と人を、見ている日にまとめて写します。** 写したあとで直します。

1. 写したい日（例：明日）の配置ボードを開く
2. 上の **［別の日から複写］** を押す
3. **複写元**の日付を選ぶ（**［前日］［1週前］** でも選べる）
4. **［○○ から複写する］** を押す

| 写るもの | 写り方 |
|---|---|
| **枠** | 日勤・夜勤とも、**全部「仮組み」**で写る |
| **人** | **［配置した人も複写する］** にチェックがあれば写る |

**写らないもの**

| 写らないもの | 理由 |
|---|---|
| **中止の枠** | 中止は写しません |
| **同じ現場・同じ区分の枠が、もうある分** | 二重にならないように、足りない分だけ作ります |
| **休みの人** | 枠は空けておきます |
| **ほかの配置と時間が重なる人** | 枠は空けておきます |

写らなかった人は、終わったあとの画面に**名前と理由**が出ます（例：「福井　休み（有給）」）。
**空いた枠は「未充足」に数えられる**ので、そこに人を入れます。

もう一度押しても、**同じ枠は増えません**（「既にあった ○件は作らず」と出ます）。

### キーボード

| キー | 動き |
|---|---|
| **↑ ↓** | 枠を選ぶ |
| **L** | 選んでいる名札を隊長にする／外す |
| **K / R / D** | 選んでいる名札を検定／列車見張／ドライバーにする。もう一度押すと外れる |

# 2. A表（週）

## 2-1. 画面の見かた

- **横が7日、縦が現場**です
- **色の付いた列と白い列が交互**になっています（列を見分けるためで、意味はありません）
- 列見出しの**青い列が「基準日」**です。右のプールは**その日**のものです
- **「—」** … その日はその現場に枠がありません
- **「重複」（赤）** … その人は**同じ時間に別の場所**にも入っています
- **「○名不足」（赤）** … 人が足りません
- **日勤**は、上の **［東京本部］［神奈川支部］** で紙を切り替えます（A表と同じ分け方）。どちらの紙かは**得意先**で決まります
- **夜勤**は1枚で、**東京本部 → 神奈川支部**の順に、濃い見出しで区切って並びます
- 下の **業務外** には、A表と同じく **研修・講習等／健康診断／管制／振替休日／有給休暇** がいつも並びます
- 一番下の **合計** の「＋研修1」は、研修など請求の無い稼働の人数です（A表の「+1」）

## 2-2. 操作

| やりたいこと | 操作 |
|---|---|
| **配置を動かす** | 名札を引っぱる。**別の日へも移せます** |
| **基準日を変える** | 列見出しの**日付を押す** |
| **前の週／次の週** | 上の **◀ ▶** |
| **得意先をどちらの紙に載せるか変える** | 得意先の画面で **A表の紙** を選んで保存 |
| **研修・健康診断・管制に入れる** | プールの名札を、業務外の **研修・講習等／健康診断／管制** の行の**その日のマスへ引っぱる** |
| **研修・健康診断・管制から外す** | そのマスの名前を**プールへ戻す**。別の日・別の行へ引っぱれば移せる |
| **その日の配置ボードへ** | 右上の **［○/○ の配置ボードへ］** |

**一括確定はこの画面にはありません。** 確定は配置ボードで行います。

# 3. 休み

## 3-1. 画面の見かた

- **縦が隊員（フリガナ順）、横が日付**です
- **半月ずつ**表示します。上の **［1〜15日］［16〜○日］** で切り替えます
- 上の **○月の休み ○件** … その月に入っている休みの数
- 地の色：**土曜＝薄い青、日曜＝薄い赤**

### マスの文字

| 文字 | 意味 |
|---|---|
| **有給**（濃い灰） | 有給（終日） |
| **休み**（濃い灰） | 休み（終日） |
| **振休**（濃い灰） | 振替休日（終日） |
| **研修／健診／管制**（濃い灰） | 業務（終日）。**ここでは入れられません**。A表（週）の業務外の欄で入れます |
| **日勤休／夜A休／夜B休**（薄い灰） | **その区分だけ休み**。ほかの区分は出られる |
| **配置**（薄い文字） | その日は**配置が入っています** |
| **赤いマス** | **配置が入っている日に休みが入っています** |

マスにカーソルを乗せると中身が文字で出ます。

## 3-2. 操作

1. 上の **［有給］［休み］［日勤のみ休み］［夜Aのみ休み］［夜Bのみ休み］［振替休日］** から**1つ選ぶ**
2. **マスを押す**

消すときは **［消す］** を選んでからマスを押します。

| やりたいこと | 操作 |
|---|---|
| **前の月／次の月** | 上の **◀ ▶** |
| **今月に戻る** | **［今月］** |
| **離れた月へ飛ぶ** | 上の**年月の欄**に入れて **［表示］** |
| **前半／後半を切り替える** | 上の **［1〜15日］［16〜○日］** |
| **隊員を探す** | 右上の入力欄に名前 |
| **フリガナで飛ぶ** | 表の左の **あ か さ た な …** を押す |
| **休みのある人だけ見る** | 右上のチェック |

## 3-3. 休みを入れると配置がどう変わるか

| 入れた休み | 配置ボードのプール |
|---|---|
| **有給・休み（終日）** | 日勤・夜勤の**どちらからも消える** |
| **日勤のみ休み** | **日勤からだけ消える**（夜勤には出る） |
| **夜Aのみ休み** | 夜勤に**残る**（夜Bには出られるため）。夜A・夜B の**両方**を入れると消える |

消えた人は、配置ボードの右下 **「非現場」に名前が出ます**。

# 4. こういうときは

| 困ったこと | どうするか |
|---|---|
| **間違えて動かした** | もう一度引っぱって戻す |
| **明日の盤面が空っぽ** | **［別の日から複写］** で似た日（例：先週の同じ曜日）を写してから直す |
| **複写したのに入っていない人がいる** | 複写のあとの画面に**名前と理由**が出ています（休み・時間の重なり）。空いた枠に別の人を入れる |
| **名札が見つからない** | プール上の**検索欄**に名前を入れる |
| **「置けません」と出た** | **同じ人が同じ時間に2か所**に入っています。どちらかを外す |
| **赤字が出たが入れたい** | NG・資格不足は**警告だけ**です。そのまま入れられます |
| **一括確定が押せない** | 確定できる仮組みが**画面に無い**ときは押せません |
| **画面が小さい** | **Ctrl** を押しながら **＋**（戻すのは **Ctrl** と **0**） |
| **表示がおかしい** | **F5** で読み込み直す |

## べんり君へ引き渡し

**［べんり君へ引き渡し］** … その日に確定した枠を、べんり君と同じ18列の CSV にして表示・ダウンロードします。
- 仮組みの枠は入りません（確定してから出す）
- **研修・欠勤はまだ入りません**
- まだ確認していない日は、黄色で「まだ確認されていません」と出ます（出すことはできます）
