## 1. CSV と SQL を作る（手元・5分）

ファイルは**古い月から順に**渡す。🔴 **マスタは最後に渡したファイルのものを使う**。

```
python scripts/extract-sites.py       docs/管制_別紙/7月.xlsm docs/管制_別紙/8月.xlsm docs/管制_別紙/9月.xlsm
python scripts/extract-assignments.py docs/管制_別紙/7月.xlsm docs/管制_別紙/8月.xlsm docs/管制_別紙/9月.xlsm
```

- 年をまたぐ場合だけ、先に `BENRI_YEAR` を指定する（シート名に年が無いため。既定は 2026）
- 🔴 **2回目以降は、まだ入れていない月のファイルだけを渡す**（10/2 に7月分で1回目を実施）。
  過去配置の SQL は同じ現場・日・区分の枠が既にあると**丸ごと止まる**ため。
  マスタは最後に渡したファイルから取るので、新しい月だけ渡せば最新になる。
  2回目は手順 2（ダミーを消す）を**飛ばす**
- 🔴 **「読んだファイル」の行数が 0 なら止まる。** シート名の形（`月.日`）が違う可能性がある

出力（すべて `local/`。🔴 Git に入れない）：

| ファイル | 中身 | 7月分の件数（目安） |
|---|---|---|
| `customers-import.csv` | 得意先マスター | 603 |
| `duties-import.csv` | 勤務マスター（警備先番号） | 1,593 |
| `sites-import.csv` | 現場一覧（〈現場名×得意先〉で1件） | 127 |
