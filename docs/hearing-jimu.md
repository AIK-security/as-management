# 自分向けメモ

- 🔴 **見本を先に見せる。** 「教えてください」ではなく「**ここ、合っていますか**」
- 🔴 **入力の話は ★D-1 まで出さない。** 誰が入れるかは相手に決めてもらう
- **深掘りは「なぜ」を1回だけ。** 2回以上は詰問になる
- 🔴 **相手が話したがる話題ほど第2弾の内容。** 線を引いて切り上げる
- 🔴 **「置き換え」「解約」「効率化で人が減る」の3語は口に出さない**
- **録音する。** このシートには「後から思い出せない情報」だけ書く
- 終わったら**その場で判定表を埋める。** 帰ってからでは思い出せない
- 赤の入った見本は**預かって持ち帰る**（受領資料と同じく Git に入れない）
