### 9-2. 🔴 設計を変えると決めたこと（5件）

#### ① 夜勤の日またぎ ── 24時以降の時刻を入力できるようにする

- 夜勤には**日付をまたぐ案件がある**。`16日 24:30 〜 翌 6:30` のような枠を入れたい
- 🔴 **これは「16日に実施した案件」として処理する**。翌日の案件に割ってはいけない
- → **開始・終了に 24時以降（24:30 など）を入力できるようにする**
- 🟠 **未決：何時までを「2〇時」表記にするか**（柴山より意見を求められている）

#### ② 🔴 休みの管理（新規・第1弾に一部が入る）

**将来の姿（第2弾・第3弾）**

- 隊員が**申請** → 管制が確認・承認 → **休みが確定** → **申請の結果が本人に伝わる**
- 申請できる区分：
  | 区分 | 内容 |
  |---|---|
  | **有給休暇** | |
  | **終日休み** | |
  | **一部勤務可**（🟠 名称は要検討） | 「日勤ならできる」「A/B 夜勤ならできる」「夜勤どちらもできる」など、<br>**勤務できる区分を指定する**休み方 |
- 🔴 **隊員の給与は固定給ではない**。**有給以外は欠勤にならず、勤務日数が減るだけ**
- 将来的には**勤務日数から給与計算**する。有給についても
  「その時点で何日付与されていて／何日使っていて／残り何日で／いつ回復し／その時何日付与されるか」
  まで管理が要る ── 🔴 **ただしそこまでは今はやらない**（第3弾）

**第1弾でやること（配置に直結する部分だけ）**

- 🔴 **休みの隊員の名札を、日別・週次どちらのプールにも出さない**
- 🔴 **プールの下部で「当日休みの隊員」を確認できる**ようにする
  （消すのではなく、**休みだと分かる形で別に置く**）

#### ③ 隊員マスタに**最寄り駅**を持たせる

#### ④ 🔴 **東京／千葉の切り替えを廃止する。東京だけでよい**

#### ⑤ 🔴 **表示倍率 110% でヘッダーが崩れる。100% 相当にきれいに収める**

- 110% にすると、東京/千葉・日勤/夜勤・仮組み/確定/未充足・「＋現場を追加」・
