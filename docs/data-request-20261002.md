# 実データ切り替えのための受領データ（2026-10-02 確認用）

**目的**：10/1 の管制 MTG で「実データでないと触ってみる気にならない」と分かった。
→ 現場・隊員・過去の配置を実データにして、**明日の配置を1回これで組んでもらう**状態を作る。

> ⚠️ **説明の一貫性**（CLAUDE.md）
> 相手には「**毎日の打ち込みを『選ぶだけ』にするため**」で通す。
> **ShiftMax の名前・置き換え・人員の話は出さない**（管制は ShiftMax を知らない）。
