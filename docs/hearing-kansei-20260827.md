- **現物を見せて聞く。** 「白紙で説明してください」より「これで合ってますか」の方が10倍速い
  - 持参するもの：**ホワイトボード写真** / **A表(段取り表)のコピー** / **べんり君の画面**

- 🚫 **聞かない話題**：契約・費用・人員。**経営／総務マター**（現場に聞くと警戒を招く）
