### 3. マスタ画面4本（`/masters/…`）

`sites` / `guards` / `customers` / `ng`。検索・ページ送りは**最初からサーバ側**（実データは現場1,593・得意先603）。

- 🔴 **NG は登録・削除ができる。** 設計が「運用開始後に貯める」前提なのに**貯める入口が無かった**ため
- 検索語から `, ( ) % *` を落とす（`.or()` は文字列で組み立てるフィルタ構文で、別の絞り込みに化ける余地がある）
- NG の一覧は**埋め込み結合を使わない**。`ng_entries` は `guards` を2本の外部キーで参照しており、
  曖昧さを解くには**制約名を推測して書く**ことになるため、2段で取って JS 側で名前を当てる

### 4. 時刻入力の2桁表示（`8:0` → `08:00`）

管制の指摘。🔴 **`type="number"` では実現できないことを実機で確認**（`"00"` を渡してもブラウザが `"0"` に正規化する）。
→ `type="text"` ＋ `inputMode="numeric"`＋自前のゼロ埋め。**上下の増減ボタンは失われた**。
後に `src/components/TwoDigitInput.tsx` へ切り出し、現場の編集画面と共有。

### 5. 🔴 性能改善（3件）

「日付の切り替えに4秒／案件の追加から反映まで6秒」（柴山の実測）への対応。

| # | 原因 | 対処 |
|---|---|---|
| 1 | 認証の問い合わせが1画面で2重（layout と page の両方が `requireStaff()`） | `getSessionProfile()` を React の `cache()` で包む。**関門は1枚も減らしていない** |
| 2 | `getBoardData()` が**8回の直列** | 「管轄 → 残り11本を並列」の**2段**へ。クエリの中身・条件・並び順は変えていない |
| 3 | 🔴 **関数が米国（`iad1`）で動き、Supabase は東京（`ap-northeast-1`）** | `vercel.json` に `"regions": ["hnd1"]`。`X-Vercel-Id` が `hnd1::iad1::` → `hnd1::hnd1::` になったことを確認 |

3 が**本番だけ遅かった理由**。DB への往復が毎回太平洋を2回横断していた。
`vercel.json` にコメントを書けないため、判断根拠と確認方法を **`README.md`「本番（Vercel）の実行リージョン」** に残した。

→ 結果：**「だいぶ早くなった」**（柴山）

## 決定事項

| # | 決定 | 理由 |
|---|---|---|
| 1 | 🔴 **管理者限定をやめる。** いま作っている段階のものは**管制が追加・編集・削除まで全操作可能** | 実際に穴が空いていた ─ 9/7 に仮番号の現場を管制が作れるようにしたのに、**本番号へ直すのは admin 限定**だった。作れるのに直せない。→ `20260908000000_masters_editable_by_control.sql` |
| 2 | **`profiles` だけは据え置く** | ロールの付け替え（自分を admin にできる）は業務ではなく**権限の境界そのもの**。開けると認可の3枚重ねが意味を失う |
| 3 | 🔴 **A表出力より先に「案件と配置の情報を正しくできる」こと**（柴山） | 情報が不完全なままでは A表も請求も成立しない。`screen-design.md` §9 の「段3 が終われば業務として成立、4以降は改善」とも一致 |
| 4 | **MTG は 9/16（水）・管制のみ** | → 段3（ShiftMax 引き渡し）は要否が決まらないので**今回も触らない** |
| 5 | **A表は「印刷ビュー」ではなく「出力」でよい**（PDF でも Excel でも可） | 実装方針：**新しいパッケージを入れず**、印刷経由の PDF ＋ CSV の2経路。🔴 CSV は UTF-8 BOM が要る（Excel の文字化け） |
| 6 | **現場の削除は詳細画面に置く** | ただし枠がある現場は DB が拒む仕様を活かし、件数を出して押させない |
| 7 | **Vercel の CLI アカウントは会社側（`aik-security`）へ切り替えた** | 個人 Team（`aik-erealty`）のセッションは置き換わる。兄弟プロジェクトを CLI で触るときは `vercel login` で戻す |
