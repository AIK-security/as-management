## 自戒

- 🔴 **`§7-2` を半月以上、中身を数えずに引用していた。**
  名前定義（列の器）から書いたものを「確定した構造」として設計に積んでいた。
  → **器があることと、埋まっていることは別。** memory の *前提は載せる前に確かめる* と同型。

- 🔴 **「事務ヒアリングが最大の待ち」と過大に評価した。**
  いつ要るか・手元で何ができるかを確かめずに「他人待ち」と書いた。
  → **他人待ちに見えたものが自分の宿題だった。** ベンダ照会6件・契約条件と同じ形を3度目。

- 🔴 **「当日変更の作り込みが残る」を、確かめずに計画へ書いた。** 実装済みだった。
  → **自分が書いた申し送りも「前提」である。** 引き継ぐ前に成立を確かめる（9/11 の自戒と同型）。

- 🔴 **`git add -A docs` で、判断待ちの PDF を巻き込んでコミットした。**
  → **範囲を絞ったつもりでも、ワイルドカードは意図を超える。** ファイルを列挙する。

- 🔴 **`python -c "..."` の中のバッククォートを bash に展開された。** 表の1行が丸ごと消えた。
  9/16 の here-string と**同じ種類の誤り**（シェルの引用符）。
  → **長い文字列・記号を含む文字列は、必ずファイル経由で渡す。** 今日はそれで統一して以降は起きなかった。

- 🟠 **heredoc が長すぎて通らず、ファイルが書けなかった**（250行超）。分割して解決。

- 🟠 **H列を「勤務区分」と読み違えた**（正しくは現場略称）。ただし同じ作業の中で §8-2 と突き合わせて訂正できた。

- 🟢 **「全行空」を `data_only` の両モードで確認してから結論にした**（*0件は疑う*）。
  数式のキャッシュ切れなら、同じ「空」でも意味がまるで違った。

- 🟢 **取込を実際に押したから不具合が出た**（*作ったら当日に1回押す*）。
