## 自戒

- 🔴 **CSP を書いたとき「Next.js は自動で nonce を付与する」と条件を確かめずにコメントまで書いていた。**
  実際は Proxy でリクエストごとに発行した場合だけ。静的ヘッダーには nonce を載せられず、
  Next のインラインスクリプトがブロックされて **hydration が完了しない**状態だった。
  **クライアントコンポーネントが1つも無かったため、今日ボタンを置くまで誰も気づけなかった。**
  さらに原因を「dev と build の衝突」と一度誤診し、ユーザーに無駄な再読み込みをさせた。
  **推測で原因を言う前にヘッダと HTML を見るべきだった**（実際、見た瞬間に分かった）。

- 🔴 **`TaskStop` が npm ラッパーしか止めず node 本体が生き残ることを確認せずに「止めた」と言い、
  その状態でビルドを走らせた。** 止めたと言うなら確認する。

- 🔴 **`rls-audit.sql` を「0行なら正常」で設計していた。**
  0行は「流し忘れ」と区別がつかない。実際、SQL Editor が最後の文しか表示しないため
  肝心の判定が隠れていた。**正常であることは明示的に言わせる。**

- 🟡 **`verify-setup.sql` に列名を直接書き、列が無い環境では CASE で守れず構文エラーになる**
  クエリを書いた。一番知りたい「未適用」の場面で結果が出なくなる。
  書いた直後に自分で気づけたのは良かった。

- 🟢 **良かった点**：`EXCLUDE` 制約がダミーデータの**物理的に不可能な配置3件**を検出した
  （同じ隊員が同じ時間帯の2枠に入っていた）。段1 の表示だけでは気づけなかった。
  **重複チェックをアプリではなく DB に置いた判断が効いた。**
